# Set up Vibe Editing

Open this repo in your agent and say **“Set up Vibe Editing for me.”**

The agent follows the [guided onboarding](plugins/vibe-editing/docs/ONBOARDING.md): it walks you
through getting your own pipeline credentials, configuring brands and delivery routes, and
checking a first local clip. [All keys and account connections](plugins/vibe-editing/docs/CONNECTIONS.md).

The same guide ships inside the plugin, so checkout and plugin installations share one setup flow.
